# Различия мжду коммандами :
# git diff — показывает побайтовые или построчные разницы между различными состояниями репозитория (например, между рабочей директорией и индексом, между двумя коммитами или ветками).
# git show — выводит подробную информацию и изменения конкретного объекта (обычно одного коммита или тега): автора, дату, сообщение и патч с тем, что именно было изменено в этом коммите.
# git log — отображает хронологическую ленту (историю) коммитов проекта с хэшами, авторами, датами и сообщениями, но по умолчанию не показывает самих изменений внутри файлов (для этого используют флаг -p).

# Kоманда git restore и команда с флагом git restore --source=<источник> различаются тем, откуда именно Git берет содержимое для восстановления файла

# git reset --hard <commit> стирает коммиты и возвращает указатель ветки и рабочую директорию строго к выбранному состоянию. Всё, что было поверх этого коммита, уничтожается в истории данной ветки.
# git revert <commit> не удаляет старые коммиты и не переписывает историю. Он создает новый коммит, который содержит обратные изменения (отменяет то, что сделал указанный коммит).

# Главное отличие в том, что ветка — это подвижная ссылка на коммит, которая сдвигается вперед по мере добавления новой работы, а тег — это фиксированная, неизменяемая метка для конкретного коммита в истории проекта.
