# git log (Лента истории)
# Что делает: Показывает список (историю) коммитов в хронологическом порядке.
# Какую информацию выводит: Хэш коммита (ID), автора, дату, сообщение коммита. Сами построчные изменения кода по умолчанию не показывает.
# Когда использовать: Чтобы найти нужный коммит или посмотреть, кто и когда вносил правки.

# git diff (Сравнение состояний)
# Что делает: Сравнивает различные состояния репозитория (файлы в рабочей директории, индекс/staged, коммиты, ветки).
# Какую информацию выводит: Исключительно разницу (diff) между выбранными сущностями (что было удалено — красным, что добавлено — зеленым).
# Когда использовать: Чтобы проверить, что вы изменили в коде прямо сейчас (до коммита) или сравнить две разные ветки.

# git show (Карточка конкретного коммита)
# Что делает: Показывает подробную информацию об одном конкретном объекте (чаще всего — о коммите).
# Какую информацию выводит: Метаданные коммита (автор, дата, сообщение) плюс полный diff изменений, которые этот коммит принёс.
# Когда использовать: Чтобы в деталях изучить один конкретный коммит по его хэшу.
