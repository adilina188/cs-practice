# Различия Git и GitHub:
# Git - локальный инструмент(программа) для контроля версий кода, а 
# GitHub - веб-платформа(сайт), созданный для хранения этих проектов в облаке и совместной работы. Проще говоря, Git — это как текстовый редактор Word на вашем компьютере, а GitHub — это как Google Документы в интернете, где вы можете делиться файлами с другими и работать вместе.
