# Различия Git и GitHub:
# Git - локальный инструмент(программа) для контроля версий кода, а 
# GitHub - веб-платформа(сайт), созданный для хранения этих проектов в облаке и совместной работы. Проще говоря, Git — это как текстовый редактор Word на вашем компьютере, а GitHub — это как Google Документы в интернете, где вы можете делиться файлами с другими и работать вместе.

# Использованные команды :
 # git status - Показывает общую сводку о состоянии рабочей директории.
 # git diff - Показывает конкретные построчные изменения (разницу), которые еще не добавлены в индекс.
 # git diff --staged - Показывает разницу для тех изменений, которые уже подготовлены и добавлены в индекс.

 # Ветка
 # Ветка в Git — это легкий и подвижный указатель на определенный коммит (состояние кода).  При создании нового коммита текущая ветка автоматически сдвигается вперед и начинает указывать на этот новый коммит. Слияние объединяет историю и код из одной ветки в другую.
